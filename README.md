# NGA 网页文本转译（disroot / PrivateBin）

把 NGA 帖子里那些"点开才能看"的 disroot 加密外链，**直接解密并把正文显示在评论下方**。不用跳浏览器，不用手动复制密码。

> 个人自用工具，与 NGA 官方无关。请遵守所在地区法律法规与论坛规则。

## 功能

- **自动识别**：按 `?<16位ID>#<base58密钥>` 指纹匹配，域名被插字、吞字、写成全角都能认出来
- **本地解密**：PBKDF2-SHA256 + AES-256-GCM 全部在设备上完成，密文与密码不出本机
- **多链接**：同一楼层最多 120 条，一页最多 240 张卡片
- **解析加速**：优先尝试无密码、相同 URL 并发合并、HTTP keep-alive 复用连接
- **折叠内容**：直接读取 `display:none` 的隐藏文本，不需要先点"展开"
- **默认 800 字**：卡片显示前 800 字，点"展开全文"看全部
- **夜色模式**：卡片右上角 ☾ 按钮，点一下全局切换，选择会记住
- **密码记忆（按帖子隔离）**：支持「后面的密码全都是 xx」这类声明；记住的密码只在本帖复用，换帖不会带入
- **失败可恢复**：解析失败显示原因，并提供"重试""打开原链"
- **不动原文**：只在楼层下方插入卡片，原评论里的链接与文字保持原样
- **未适配提示**：NGA 版本与开发目标不一致时，页面顶部显示提示，避免静默失效

## 安装

### 方式一：手机安装器（推荐，无需电脑）

1. 下载 `NGAExt-Installer-x.y.z.apk` 并安装
2. 打开后点 **① 生成补丁包**（约 30–90 秒）
3. 点 **② 卸载 NGA**（系统弹窗，**会清空登录**）
4. 点 **③ 安装补丁包**（系统弹窗）
5. 打开 NGA，重新登录一次

补丁包的签名与官方不同，所以必须先卸载再安装，这一步无法跳过。

### 方式二：电脑 EXE（手机零安装）

1. 启动 MuMu 模拟器，或手机用 USB 连接并打开「USB 调试」
2. 双击 `NGAExt-Setup-x.y.z.exe`
3. 手机上如弹出「允许 USB 调试」→ 点允许

安装器会从设备里提取已安装的 NGA、打上模块、再装回去，**不包含任何 NGA 官方安装包**。

### 方式三：手动（已 root / 已装 LSPosed）

把 `module.apk` 装进 LSPosed，作用域勾选 `gov.pianzong.androidnga`，重启 NGA。

## 使用

进入任意帖子，楼层里有 disroot 外链时会自动出现卡片：

```
┌──────────────────────────────────┐
│ ◆ 网页文本已转译到此处   外链1/3 ☾ │
│ （正文，默认 800 字）              │
│ [ 展开全文（共 15367 字） ]        │
│ 已本地解密  bin.disroot.org·15367字 │
│ 复制  原链                        │
└──────────────────────────────────┘
```

- **☾ / ☀**：切换夜色模式，点任意一张卡即可全局生效
- **展开全文**：仅在正文超过 800 字时出现
- **复制**：复制完整正文
- **原链**：用浏览器打开原始链接
- 解析失败时按钮变成 **重试** / **打开原链**

## 隐私与安全

| 项 | 说明 |
|---|---|
| 解密位置 | 全部在设备本地，使用系统自带的 JCE |
| 数据上传 | 无。不采集、不上报、无统计 |
| 密码 | 优先取评论里写的密码，其次用「后面的密码全都是 xx」这类声明，再试本帖内见过的密码；只在本机保存候选，不联网 |
| 缓存 | 解密结果存在 App 缓存目录，用于二次访问加速；卸载即消失 |
| 网络 | 只访问密文所在的 paste 站点，请求的就是你看到的那个链接 |

> 电脑版安装器会在 `%TEMP%\NGAExt-cache` 暂存一份官方 APK（7 天自动失效），用于更新插件时不必先卸了重装官方版。删除该目录即可立刻清除。

## 常见问题

**Q：更新 NGA 时提示"更新被插件挡住了"？**
A：改过的包签名和官方不同，装不进去。按弹窗提示：卸载 → 装官方新版 → 重新运行安装器。

**Q：卸载会不会丢登录？**
A：会。这是签名变更的必然代价，只能重新登录一次。

**Q：手机安装器和电脑安装器可以混用吗？**
A：不能直接混用。手机端首次打补丁会生成/使用本地签名密钥（缓存在 App 内），电脑端使用 LSPatch 默认密钥，两者签名不同；换用另一种方式前需要先卸载 NGA（会清登录）。建议固定使用一种安装方式。

**Q：为什么有的链接解不开？**
A：三类原因：密文已被服务器删除/过期；密钥被删掉字符（信息已丢失）；旧版 v1 格式（暂不支持）。

**Q：杀毒软件报毒？**
A：安装器内含 adb 与自解压结构，容易被启发式误报。可自行用 `build.ps1` 从源码构建。

**Q：支持 Mac / Linux 吗？**
A：电脑版目前仅 Windows。手动方式（LSPosed）跨平台通用。

## 构建

需要 JDK 17、Android SDK、Gradle，以及 `tools/lspatch.jar`（从 [LSPatch Releases](https://github.com/LSPosed/LSPatch/releases) 下载）。

```powershell
# 模块（Xposed）
cd ngaext
gradle assembleDebug

# 手机安装器 APK
cd ngaext-installer
gradle assembleDebug

# 电脑一键包（自动 jlink 运行时 + 打包自解压 EXE）
.\build.ps1 -Version 0.1.0 `
  -JdkPath "C:\Program Files\Java\jdk-17" `
  -SdkPath "$env:LOCALAPPDATA\Android\Sdk" `
  -GradlePath "C:\gradle\bin\gradle.bat" `
  -GradleUserHome "$env:USERPROFILE\.gradle"
```

### 目录结构

```
ngaext/             Android 模块（Xposed）
ngaext-installer/   手机端安装器 App
installer/          电脑安装器源码（bat / ps1 / 自解压 stub）
ios-tweak/          iOS 越狱 tweak（Theos 骨架，未实机验证）
build.ps1           电脑端一键打包
tools/lspatch.jar   第三方：LSPatch（不随仓库分发）
dist/               构建产物
```
