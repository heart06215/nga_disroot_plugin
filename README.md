# NGA 网页文本转译（disroot / PrivateBin）

把 NGA 帖子里那些"点开才能看"的 disroot 加密外链，**直接解密并把正文显示在评论下方**。不用跳浏览器，不用手动复制密码。

> 当前版本 **v0.1**。个人自用工具，与 NGA 官方无关。请遵守所在地区法律法规与论坛规则。

## 功能

- **自动识别**：按 `?<16位ID>#<base58密钥>` 指纹匹配，域名被插字、吞字、写成全角都能认出来
- **本地解密**：PBKDF2-SHA256 + AES-256-GCM 全部在设备上完成，密文与密码不出本机
- **多链接**：同一楼层最多 300 条，一页最多 600 张卡片；超出时明确提示，不再静默截断
- **解析加速**：优先尝试无密码、相同 URL 并发合并、HTTP keep-alive 复用连接，首次扫描不再逐个克隆楼层 DOM
- **折叠内容**：直接读取 `display:none` 的隐藏文本，不需要先点"展开"；楼层内和独立楼中楼容器都会扫描
- **支持站点**：`bin.disroot.org`、`paste.disroot.org`、`paste.to`（PrivateBin v2）
- **默认 800 字**：卡片显示前 800 字，点"展开全文"看全部；可在设置里改为 800 / 3000 / 8000 字
- **直接显示全文**：设置面板顶部有醒目的开关，开启后卡片不再折叠，直接展示完整正文
- **默认白色**：新安装默认使用浅色纸张样式；需要深色时再手动开夜色模式
- **夜色模式**：卡片右上角 ☾ 按钮，点一下全局切换，选择会记住
- **密码记忆（按帖子隔离）**：支持「后面的密码全都是 xx」这类声明；记住的密码只在本帖复用，换帖不会带入
- **手动密码**：解析失败时可点"输入密码"，确定后只在本帖内自动尝试该密码
- **失败可恢复**：解析失败显示原因，并提供"输入密码""重试""打开原链"；服务维护时会显示检查提示
- **设置面板**：卡片右上角 ⚙ 可打开设置，包含 GitHub 仓库地址、直接显示全文、夜色、预览长度、清理解密缓存、清除密码记忆
- **不动原文**：只在楼层下方插入卡片，原评论里的链接与文字保持原样
- **未适配提示**：NGA 版本与开发目标不一致时，页面顶部显示提示；9.9.x 版本不误报
- **退出即清理**：离开帖子时自动清空解密正文缓存；密码记忆仍可在设置里手动清除

## 安装

### 方式一：一键 APK（推荐）

下载 `NGAExt-OneClick-v0.1.apk`，这是**已经内置插件的 NGA 9.9.69 完整安装包**，装完直接打开使用，不需要再运行安装器。

1. 官方 NGA 和它的签名不同，首次安装前需要先卸载官方版（会清空一次登录）
2. 安装 `NGAExt-OneClick-v0.1.apk`
3. 打开 NGA，插件已经生效

之后如果拿到同一密钥签名的更新版一键 APK，可以直接覆盖安装，通常不用再卸载。

### 方式二：手动（已 root / 已装 LSPosed）

把 `NGAExt-Module-v0.1.apk` 装进 LSPosed，作用域勾选 `gov.pianzong.androidnga`，重启 NGA。这样保留官方安装包，不需要卸载。

### 方式三：安装器（仅源码构建/开发用）

`ngaext-installer` 的源码仍保留，用于从已安装的 NGA 现场生成补丁；普通使用不需要它。电脑版安装器也不再作为主要分发方式。

## 使用

进入任意帖子，楼层里有 disroot 外链时会自动出现卡片：

```
┌──────────────────────────────────┐
│ ◆ 网页文本已转译到此处  外链1/3 ☾ ⚙ │
│ （正文，默认 800 字）              │
│ [ 展开全文（共 15367 字） ]        │
│ 已本地解密  bin.disroot.org·15367字 │
│ 复制  原链                        │
└──────────────────────────────────┘
```

- **☾ / ☀**：切换夜色模式，点任意一张卡即可全局生效
- **⚙**：打开设置面板，查看 GitHub 仓库、开启"直接显示全文"、调整预览长度、清理解密缓存/密码记忆
- **直接显示全文**：设置顶部醒目开关；开启后当前和后续卡片都不再折叠
- **展开全文**：仅在正文超过当前预览长度（默认 800 字）且未开启"直接显示全文"时出现
- **复制**：复制完整正文
- **原链**：用浏览器打开原始链接
- 解析失败时按钮为 **输入密码** / **重试** / **打开原链**

## 隐私与安全

| 项 | 说明 |
|---|---|
| 解密位置 | 全部在设备本地，使用系统自带的 JCE |
| 数据上传 | 无。不采集、不上报、无统计 |
| 密码 | 优先取评论里写的密码，其次用「后面的密码全都是 xx」这类声明，再试本帖内见过的密码；只在本机保存候选，不联网 |
| 缓存 | 解密结果存在 App 缓存目录，用于二次访问加速；退出帖子自动清理，也可在设置里立即清理 |
| 网络 | 只访问密文所在的 paste 站点，请求的就是你看到的那个链接 |

> 电脑版安装器会在 `%TEMP%\NGAExt-cache` 暂存一份官方 APK（7 天自动失效），用于更新插件时不必先卸了重装官方版。删除该目录即可立刻清除。

## 常见问题

**Q：更新 NGA 时提示"更新被插件挡住了"？**
A：官方版签名和改版不同，系统不允许直接覆盖。先卸载改版，装官方新版，再重新运行安装器；插件自身的模块更新可以直接覆盖，不需要卸载。

**Q：卸载会不会丢登录？**
A：只有从官方版切到改版、或签名不匹配时才需要卸载，会清空登录。之后用同一安装方式的模块更新会保留数据；安装器不会额外备份用户空间。

**Q：一键 APK 更新会丢登录吗？**
A：首次从官方版切换必须先卸载，登录会丢一次；之后用同一密钥的一键 APK 覆盖安装，通常保留数据。若服务端把旧会话判失效，只能重新登录。

**Q：为什么有的链接解不开？**
A：三类原因：密文已被服务器删除/过期；密钥被删掉字符（信息已丢失）；旧版 v1 格式（暂不支持）。

**Q：杀毒软件报毒？**
A：安装器内含 adb 与自解压结构，容易被启发式误报。可自行用 `build.ps1` 从源码构建。

**Q：支持 Mac / Linux 吗？**
A：电脑版目前仅 Windows。手动方式（LSPosed）跨平台通用。

## 构建

需要 JDK 17、Android SDK、Gradle，以及 `tools/lspatch.jar`（从 [LSPatch Releases](https://github.com/LSPosed/LSPatch/releases) 下载）。

手机安装器需要 `ngaext-installer/app/src/main/assets/default.bks`（与电脑端 LSPatch 默认签名密钥一致）。该密钥**不随仓库分发**；自行构建时请放入你自己的密钥，或从已构建的安装器 APK 中获取。仓库 CI 只验证编译和 JS 解密测试，不会上传任何签名密钥。

```powershell
# 模块（Xposed）
cd ngaext
gradle assembleDebug

# 一键 APK：用官方 NGA APK + 模块现场合并
# 官方 APK 需自备，仓库不包含 NGA 官方安装包
java -jar ..\tools\lspatch.jar .\official-nga.apk `
  -m .\app\build\outputs\apk\debug\app-debug.apk `
  -o ..\dist -l 2 --force

# 手机安装器 APK（仅开发/现场补丁）
cd ..\ngaext-installer
gradle assembleDebug

# 电脑一键包（自动 jlink 运行时 + 打包自解压 EXE）
.\build.ps1 -Version 0.1 `
  -JdkPath "C:\Program Files\Java\jdk-17" `
  -SdkPath "$env:LOCALAPPDATA\Android\Sdk" `
  -GradlePath "C:\gradle\bin\gradle.bat" `
  -GradleUserHome "$env:USERPROFILE\.gradle"
```

### 目录结构

```
ngaext/             Android 模块（Xposed）
ngaext-installer/   手机端安装器 App
installer/          电脑安装器源码（bat / ps1 / 自解压 stub）
ios-tweak/          iOS 越狱 tweak（Theos 骨架，未实机验证）
tests/              Node 解密/识别回归测试
.github/workflows/  CI（编译模块/安装器 + JS 测试）
build.ps1           电脑端一键打包
tools/lspatch.jar   第三方：LSPatch（不随仓库分发）
dist/               构建产物
```
